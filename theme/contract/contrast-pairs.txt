# Diese Paarungen stehen hier, damit niemand sie für übersehen hält. Wer eine
# davon braucht, nimmt das genannte Ersatz-Token.
#
#   --avd-academy-color-border / --avd-academy-border-soft auf jeder Fläche
#       1,05–1,82:1. Haarlinien zwischen Zeilen und Karten sind SCHMUCK, kein
#       Bedeutungsträger: Was sie trennen, trennt auch der Abstand. 1.4.11
#       verlangt für sie nichts. Ein Rahmen, der einen ZUSTAND anzeigt, nimmt
#       eine Statusfarbe.
#
#   --avd-academy-color-warning und --avd-academy-fill-3 (Gold) auf heller
#   Fläche: 2,42:1 auf `-bg`, 2,07:1 auf `-bg-subtle`.
#       Gold trägt auf Weiß nicht. Als SCHRIFT gibt es dafür
#       `--avd-academy-color-warning-ink` (5,33:1); als Strich `-tone-3` – der
#       aber auf heller Fläche denselben Wert hat und deshalb ebenfalls nicht
#       zugesagt ist (siehe unten).
#
#   --avd-academy-tone-3 auf heller Fläche: 2,42:1 bzw. 2,07:1.
#       Der einzige Ton, der als Strich nicht in beiden Modi trägt (dunkel:
#       10,03:1). Ihn aufzuwerten hieße, einen Token-WERT zu ändern – das ist
#       eine eigene Entscheidung und nicht Teil dieser Zusage.
#
#   --avd-academy-tone-2 auf --avd-academy-color-bg-subtle: 2,75:1 hell.
#       Orange trägt auf der Seitenfläche (3,22:1), auf der abgesetzten nicht.
#
#   --avd-academy-color-primary / -info / --avd-academy-fill-1 auf dunkler
#   Fläche: 1,53:1.
#       Slate auf dunklem Grund verschwindet. Dafür gibt es `-tone-1`.
#
#   --avd-academy-color-primary-light: 3,19:1 hell auf `-bg`, 2,73:1 auf
#   `-bg-subtle`.
#       Führt laut Token-Kommentar „Rahmen/neutrale Linien“ – dieselbe
#       Schmuck-Begründung wie bei den Haarlinien.
#
#   --avd-academy-color-ink-muted auf --avd-academy-hero-bg: 4,84:1.
#       Siehe oben – das Hero-Band folgt der Schulungsfarbe.
